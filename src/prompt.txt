## CROSS-TAB NAVIGATION

| From Tab | Action | To Tab | Result |
|----------|--------|--------|--------|
| Analysis | Click chart icon next to feature | Charts | Open specific chart |
| Analysis | Click export icon next to feature | Export | Pre-select feature |
| Charts | Click "View Data" button | Analysis | Highlight feature row |
| Charts | Click "Export This" button | Export | Pre-select feature + PNG |
| Export | Click "View in Analysis" link | Analysis | Jump to feature row |
| Export | Click "Preview Chart" link | Charts | Open chart modal |

## STATE MANAGEMENT

Shared State Across Tabs:
- Selected text file (FP_01.txt to C_35.txt)
- Current feature filter (All / Tier 1 / Tier 2 / Tier 3 / Flagged)
- Threshold settings (editable CV cutoff, etc.)
- Comparison mode (single text vs. two texts vs. corpus average)

Tab-Specific State:
- Analysis: Sort column, sort direction, row expansion
- Charts: Zoom level, selected chart, animation play state
- Export: Selected formats, download queue, progress

## PROMPT FOR DEVELOPER

Implement a React-based web application with three primary tabs: Analysis, Charts, and Export. Use Recharts for visualizations, compromise.js for NLP processing, and file-saver for downloads. Maintain shared state via React Context. Ensure all 18 features are mapped as specified above. Color scheme: ColorBrewer 2.0 palette. Responsive design: minimum width 1024px for Analysis, 1200px for Charts. Accessibility: keyboard navigation, screen reader labels, high contrast mode.
